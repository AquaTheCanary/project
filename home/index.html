A few quick answers

Good to know.

New here? These are the basics.

What can I create with Project?

Use Project Present for interactive presentations, Project Sites for websites, Project Forms for surveys, Product Canvas for visual design and Project Ready for code-driven apps.

Can I publish a website?

Yes. The website builder supports publishing to a Project address, with custom-domain setup for domains you own.

Is Project free?

Yes. The workspace is designed to be free to use, with no subscription tiers.

Can I present to an audience?

Yes. Presentations include separate presenter and audience experiences.
